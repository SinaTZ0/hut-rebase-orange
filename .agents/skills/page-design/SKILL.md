# Page Design

Read [docs/design-flow.md](../../../docs/design-flow.md) and follow its steps for the page you were asked to build. It links the other docs you need along the way (`app-identity.md`, `shadcn.md`, `components.md`).

- Write the page brief (step 3) in your reply before writing code, so it can be reviewed and adjusted.
- If the page needs a new or restyled primitive, do that first as its own change (step 5).
- Finish with the review (step 7) and report anything in the brief the page doesn't meet yet.
