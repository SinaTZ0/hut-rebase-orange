Lucide outline icons (ISC licence), 24×24 grid, 1.75px round strokes, the set the components use. Each file is drawn in the single ink #134542 (`primary` light) because `<img>` cannot inherit colour; for use in markup copy the SVG and set `stroke="currentColor"` so the icon follows its text colour. Directional icons are not mirrored: use `arrow-left` for forward actions in right-to-left layouts.
