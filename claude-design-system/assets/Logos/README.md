The Sarv emblem: a gateway arch holding a cypress leaf, 48×48 viewBox, a single ink. It is a placeholder for the university's official mark. `sarv-mark-teal.svg` is drawn in `primary` light (#134542) for light grounds; `sarv-mark-gold.svg` is drawn in `accent` light (#e9b43c) for `surface-deep` grounds. Because `<img>` cannot inherit colour, recolour a copy of the inline SVG for the dark theme (`primary` dark, #7ad6c7).
