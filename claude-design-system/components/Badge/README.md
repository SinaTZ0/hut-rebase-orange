A pill label for a category, term or status. `sv-badge` alone is the quiet teal wash (terms, categories); `sv-badge--accent` marks one featured item per card; the four status tones (`success`, `warning`, `danger`, `info`) always carry an icon and a word, because colour alone does not tell status apart.

The consumer provides short text (three words at most) and, for status tones, the icon. Use the `caption` or `kicker` type style inside. Do not use a badge as a button.
