A floating `surface-raised` panel of up to six quick-access tiles, each an icon in a `primary-soft` square, a `h4` title and a `body-sm` subtitle. On the homepage add `sv-services--overlap` so the strip overlaps the hero by `space-9`; elsewhere omit it.

The consumer provides the destinations (links to the university's systems), one outline icon per tile (Lucide, 28px) and a title of two words or fewer. The last tile is always the catch-all «کلیه خدمات». Under 960px the strip becomes three columns, under 600px two.
